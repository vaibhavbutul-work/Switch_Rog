# Switch_Rog

## Project Overview

Switch_Rog is a collaborative AI development environment designed for a team of developers.

It integrates Mattermost, Switch, OpenCode and GitHub to allow developers and AI agents to collaborate through a shared communication environment.

## Technology Stack

* Mattermost – Team communication
* Switch – Connects messaging platforms with AI agents
* OpenCode – AI coding agent
* GitHub – Version control and collaboration
* Docker – Container deployment
